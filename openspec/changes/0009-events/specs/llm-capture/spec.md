# Spec Delta

## ADDED Requirements

### Requirement: Разбор не работает со списками событий

Разбор текста и голоса MUST NOT создавать события. Списки с kind `events` MUST
NOT передаваться в LLM в составе контекста и MUST NOT выбираться целевым
списком элемента черновика, в том числе при совпадении имени списка с текстом
пользователя или ответом LLM. Внешний capture с явно указанным списком событий
MUST отклоняться ошибкой валидации `422` до обращения к LLM.

#### Scenario: Явный список событий во внешнем capture

- **WHEN** клиент вызывает внешний capture и передаёт идентификатор списка
  «Календарь» с kind `events`
- **THEN** система возвращает `422`
- **AND** LLM не вызывается и квота не расходуется

#### Scenario: Фраза с интервалом

- **WHEN** пользователь пишет «маникюр завтра с 14 до 15:30»
- **THEN** черновик содержит задачу в списке задач
- **AND** событие не создаётся

#### Scenario: Имя списка событий в ответе LLM

- **WHEN** LLM указывает целевым списком «Календарь», а в household есть список
  событий с таким именем
- **THEN** система выбирает список по умолчанию для kind элемента
- **AND** отмечает в черновике, что список выбран автоматически

#### Scenario: Контекст запроса

- **WHEN** система собирает запрос к LLM для household со списками «Задачи»,
  «Покупки» и «Календарь»
- **THEN** в перечне списков запроса есть «Задачи» и «Покупки»
- **AND** списка «Календарь» в нём нет
