# Spec Delta

## MODIFIED Requirements

### Requirement: Календарные вхождения

Система SHALL возвращать календарные вхождения задач и событий за запрошенный
интервал `[start, end)`, включая задачи со сроком, события и развёрнутые
вхождения повторяющихся серий. Каждое вхождение MUST содержать идентификатор
элемента, тип элемента (`tasks` или `events`), детерминированный ключ
вхождения, начало, конец, признак `all_day`, название и статус. Конец вхождения
события MUST соответствовать концу события; конец в ответе исключающий, поэтому
для вседневного события это день, следующий за последним. Событие, которое
началось до интервала и ещё идёт в нём, MUST входить в ответ. Интервал запроса
MUST быть не больше 366 дней. Календарь MUST быть доступен только для чтения;
создание и редактирование задач и событий через календарь не поддерживаются.

#### Scenario: Задачи со сроком

- **WHEN** клиент запрашивает календарь за ноябрь
- **THEN** система возвращает все открытые и завершённые задачи со сроком в
  ноябре
- **AND** вседневные задачи имеют `all_day = true`

#### Scenario: Повторяющиеся вхождения

- **WHEN** клиент запрашивает календарь за месяц для еженедельной задачи
- **THEN** система возвращает все вхождения серии в этом месяце
- **AND** каждое вхождение имеет уникальный детерминированный ключ

#### Scenario: Слишком широкий интервал

- **WHEN** клиент запрашивает календарь более чем на 366 дней
- **THEN** система возвращает ошибку валидации
- **AND** не выполняет развёртку повторений

#### Scenario: Событие с концом

- **WHEN** событие идёт `2026-11-11` с 14:00 до 15:30 и клиент запрашивает
  календарь за ноябрь
- **THEN** вхождение имеет тип `events`, начало 14:00 и конец 15:30

#### Scenario: Событие без конца

- **WHEN** событие начинается `2026-11-11` в 10:00 и не имеет конца
- **THEN** вхождение имеет начало 10:00 и конец 11:00

#### Scenario: Многодневное событие

- **WHEN** вседневное событие идёт с `2027-03-05` по `2027-03-10` включительно
- **THEN** вхождение имеет `all_day = true`, начало `2027-03-05` и конец
  `2027-03-11`

#### Scenario: Событие, начавшееся до интервала

- **WHEN** вседневное событие идёт с `2027-02-27` по `2027-03-02`, а клиент
  запрашивает календарь за март
- **THEN** вхождение входит в ответ со своими началом и концом

#### Scenario: Повторяющееся событие

- **WHEN** событие повторяется по вторникам с 18:00 до 19:00 и клиент
  запрашивает календарь за месяц
- **THEN** система возвращает вхождение на каждый вторник месяца с началом
  18:00 и концом 19:00
