# Spec Delta

## MODIFIED Requirements

### Requirement: Todo-сущности по спискам

Система SHALL создавать одну сущность `todo` для каждого неархивированного
списка household, кроме списков событий: для списка с kind `events` сущность
`todo` MUST NOT создаваться. `unique_id` сущности MUST быть стабильным и
строиться из идентификатора household и идентификатора списка. Сущность MUST
поддерживать создание, редактирование, удаление и завершение позиций. Поля
`title`, `description`, `due` и `status` MUST синхронизироваться в обе стороны.

#### Scenario: Создание списка

- **WHEN** в Tasklerq появляется новый список «Дача»
- **THEN** после обновления координатора в Home Assistant появляется
  `todo.dacha`
- **AND** сущность содержит открытые позиции списка

#### Scenario: Создание позиции из Home Assistant

- **WHEN** пользователь создаёт позицию «Купить лампочку» через `todo`
- **THEN** Tasklerq создаёт позицию в соответствующем списке
- **AND** она появляется в Telegram

#### Scenario: Завершение из Home Assistant

- **WHEN** пользователь отмечает позицию выполненной в `todo`
- **THEN** Tasklerq завершает её с автором `Home Assistant`
- **AND** изменение отражается в Telegram

#### Scenario: Список событий

- **WHEN** у household есть список «Календарь» с kind `events`
- **THEN** сущность `todo` для него не создаётся
- **AND** события этого списка видны в календарной сущности

### Requirement: Календарная сущность

Система SHALL создавать одну read-only сущность `calendar` для задач со сроком
и событий. События календаря MUST содержать название, описание, начало, конец,
признак `all_day` и идентификатор элемента. Задачи со временем MUST
отображаться как события со временем; вседневные задачи MUST отображаться как
all-day события. События Tasklerq MUST отображаться со своим началом и концом,
включая многодневные. Повторяющиеся задачи и события MUST разворачиваться в
отдельные события на горизонте, настроенном в options. Сущность MUST NOT
предлагать создание, редактирование или удаление событий.

#### Scenario: Событие со временем

- **WHEN** задача назначена на `2026-11-03 18:00`
- **THEN** календарь показывает событие с началом в `18:00`
- **AND** событие содержит название задачи

#### Scenario: Вседневная задача

- **WHEN** задача имеет `due_date = 2026-11-03`
- **THEN** календарь показывает all-day событие на эту дату
- **AND** событие не занимает время в сетке дня

#### Scenario: Повторяющаяся задача

- **WHEN** задача повторяется еженедельно по вторникам
- **THEN** календарь показывает отдельные события на каждом вторнике в
  пределах горизонта
- **AND** события имеют разные детерминированные ключи

#### Scenario: Попытка редактирования

- **WHEN** пользователь пытается создать событие через сущность Tasklerq
- **THEN** сущность не предоставляет такую возможность
- **AND** Tasklerq не создаёт задачу из события календаря

#### Scenario: Событие Tasklerq с концом

- **WHEN** событие «Маникюр» идёт `2026-11-11` с 14:00 до 15:30
- **THEN** календарь показывает событие с началом 14:00 и концом 15:30

#### Scenario: Многодневное событие Tasklerq

- **WHEN** вседневное событие «Отпуск» идёт с 5 по 10 марта включительно
- **THEN** календарь показывает одно all-day событие на шесть дней
