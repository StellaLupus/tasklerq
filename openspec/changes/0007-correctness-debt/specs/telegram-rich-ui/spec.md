## ADDED Requirements

### Requirement: Баннер при несобираемом экране

Если фоновый результат (разбор, прямое добавление, ошибка разбора) нужно
показать баннером над текущим экраном, а этот экран больше не собирается
(его задачу или список удалили), бот MUST показать тот же баннер с его
кнопками над главным меню. Баннер MUST NOT теряться.

#### Scenario: Список удалён, пока шёл разбор

- **WHEN** пользователь отправил текст на экране списка, а до конца разбора
  этот список удалили
- **THEN** результат приходит баннером над главным меню
- **AND** кнопки баннера сохраняются

### Requirement: Отмена прямого добавления покупок

«↩️ Отменить» прямого добавления MUST оставлять пользователя на текущем
экране, если это не экран целевого списка, и MUST сохранять кнопку «Открыть»
ожидающего черновика того же добавления. Баннер после выбора по дубликату
MUST сохранять «↩️ Отменить» для позиций, созданных этим добавлением ранее.

#### Scenario: Отмена над карточкой задачи

- **WHEN** покупки добавлены, пока открыта карточка задачи, часть текста ушла в
  черновик, и пользователь нажал «↩️ Отменить» в баннере
- **THEN** созданные позиции удалены, и карточка задачи остаётся на экране
- **AND** в баннере есть «Открыть» для черновика

#### Scenario: Отмена после выбора по дубликату

- **WHEN** прямое добавление создало «Хлеб» и предложило выбор по «Молоко», и
  пользователь выбрал «➕ Увеличить»
- **THEN** следующий баннер содержит «↩️ Отменить» для «Хлеб»

### Requirement: «Без срока» у задачи без срока

Если на экране быстрого срока у задачи без срока нажали «Без срока», бот
MUST показать карточку без баннера «Срок снят», и версия задачи MUST NOT
расти.

#### Scenario: Срока не было

- **WHEN** у задачи без срока на экране быстрого срока нажали «Без срока»
- **THEN** открывается карточка без баннера
- **AND** версия задачи не изменилась
