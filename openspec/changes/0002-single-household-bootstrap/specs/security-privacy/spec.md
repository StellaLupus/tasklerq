# Spec Delta

## ADDED Requirements

### Requirement: Управление API-токенами владельцем в Telegram

Система SHALL предоставлять владельцу household в боте экран «Интеграции». На
нём показываются активные API-токены household (имя, префикс, области действия,
время последнего использования), есть отзыв токена с подтверждением и выпуск
токена для Home Assistant с областями `ha:read`, `ha:write`, `capture:write`.
Участник без роли `owner` MUST NOT видеть экран и выполнять действия с токенами.
Выпуск и отзыв MUST записываться в аудит с владельцем в качестве актора.

#### Scenario: Выпуск токена для Home Assistant

- **WHEN** владелец нажимает «Выпустить токен для HA»
- **THEN** создаётся токен с именем «Home Assistant» и областями `ha:read`,
  `ha:write`, `capture:write` без срока действия
- **AND** в аудите есть событие создания токена с именем, областями и актором
  владельцем, без самого токена

#### Scenario: Список токенов

- **WHEN** владелец открывает «Интеграции», а в household есть токены,
  выпущенные через CLI и через бот
- **THEN** экран показывает все активные токены household с префиксом, но без
  полного значения
- **AND** отозванные и истёкшие токены не показываются как активные

#### Scenario: Отзыв токена

- **WHEN** владелец нажимает «Отозвать» у токена и подтверждает действие
- **THEN** токен отзывается
- **AND** следующий запрос с ним получает `401`
- **AND** в аудите есть событие отзыва

#### Scenario: Участник открывает интеграции

- **WHEN** участник с ролью `member` пытается открыть «Интеграции» или
  использовать устаревшую кнопку отзыва
- **THEN** система отказывает в действии
- **AND** токены не меняются

#### Scenario: Токен чужого household

- **WHEN** действие отзыва ссылается на токен другого household
- **THEN** система отвечает как на несуществующий токен
- **AND** токен не отзывается

### Requirement: Одноразовый показ токена в Telegram

Система SHALL показывать открытое значение выпущенного в боте токена один раз,
отдельным сообщением, скрытым под спойлером, с кнопкой «Я сохранил». Нажатие
кнопки MUST удалять сообщение с токеном. Открытое значение MUST NOT сохраняться
в базе: ни в очереди исходящих сообщений после доставки, ни в состоянии экранов,
ни в callback-данных, ни в логах. Повторно показать токен MUST NOT быть возможно.

#### Scenario: Показ и удаление

- **WHEN** токен выпущен, а владелец нажимает «Я сохранил»
- **THEN** сообщение с токеном удаляется из чата
- **AND** экран «Интеграции» показывает новый токен только по префиксу

#### Scenario: Сообщение старше 48 часов

- **WHEN** владелец нажимает «Я сохранил», а удалить сообщение средствами
  Telegram уже нельзя
- **THEN** сообщение редактируется так, что токен в нём больше не виден

#### Scenario: Токен не остаётся в базе

- **WHEN** сообщение с токеном доставлено
- **THEN** ни в одной таблице базы нет открытого значения токена
- **AND** в базе хранится только хеш и префикс

#### Scenario: Ошибка доставки

- **WHEN** сообщение с токеном не удалось доставить после всех попыток
- **THEN** открытое значение удаляется из очереди исходящих сообщений
- **AND** владелец может выпустить новый токен
