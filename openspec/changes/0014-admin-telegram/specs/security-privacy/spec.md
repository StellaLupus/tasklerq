# Spec Delta

## MODIFIED Requirements

### Requirement: Секреты и доступ к инфраструктуре

Система SHALL хранить секреты в переменных окружения, env-file с правами `0600`,
Docker secrets или в базе в зашифрованном виде ключом `TASKLERQ_SECRET_KEY`,
который задаётся только окружением. Секреты MUST NOT попадать в репозиторий,
образ, логи, diagnostics, трассировки, сообщения об ошибках и в выгрузки
household; единственное исключение — setup-код консоли, который выводится в лог,
пока учётной записи администратора нет. Секреты MUST поддерживать ротацию без
пересборки образа; секреты, заданные в консоли, MUST поддерживать ротацию без
перезапуска процесса. Зависимости MUST проверяться на известные уязвимости в
CI.

#### Scenario: Diagnostics

- **WHEN** скачивается diagnostics Home Assistant
- **THEN** токен и пароль базы отсутствуют
- **AND** URL не содержит учётных данных

#### Scenario: Ротация токена бота

- **WHEN** администратор меняет `TELEGRAM_BOT_TOKEN`
- **THEN** сервис перезапускается с новым токеном
- **AND** старый токен перестаёт использоваться
- **AND** webhook перерегистрируется

#### Scenario: Ротация токена бота в консоли

- **WHEN** администратор заменяет токен того же бота в консоли
- **THEN** новый токен начинает использоваться без перезапуска процесса
- **AND** старый токен перестаёт использоваться
- **AND** webhook перерегистрируется

#### Scenario: Уязвимая зависимость

- **WHEN** CI обнаруживает критическую уязвимость в зависимости
- **THEN** сборка блокируется до обновления или явного исключения
- **AND** исключение фиксируется с обоснованием

#### Scenario: Резервная копия базы без ключа

- **WHEN** резервная копия базы с сохранённым токеном слота восстановлена на
  другом сервере без `TASKLERQ_SECRET_KEY`
- **THEN** токен слота не может быть прочитан
- **AND** остальные данные восстановлены полностью
