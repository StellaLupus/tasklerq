# Spec Delta

## ADDED Requirements

### Requirement: Отметка задач в утренней сводке

Открытая задача разделов «Сегодня» и «Просрочено» сводки SHALL быть кнопкой
на всю ширину; касание MUST выполнять задачу и править сводку на месте, без
экрана навигации. Касание выполненной задачи MUST отменять выполнение по общим
правилам отмены, а при отказе — показывать тост. Выполненная другим
участником задача MUST показывать его имя и не иметь кнопки, если правила не
дают пользователю отменить выполнение. События — строки без кнопок.

#### Scenario: Выполнить задачу из сводки

- **WHEN** в сводке есть «☐ Вынести мусор · весь день», а пользователь нажимает
  на эту строку
- **THEN** задача выполняется
- **AND** сводка правится на месте, строка показывает «✅ Вынести мусор»
- **AND** новый экран навигации не присылается

#### Scenario: Отменить выполнение из сводки

- **WHEN** пользователь выполнил задачу из сводки и через минуту снова нажал на
  её строку
- **THEN** задача снова открыта
- **AND** строка снова показывает «☐ Вынести мусор · весь день»

#### Scenario: Отмена после окна

- **WHEN** задачу выполнили из сводки 15 минут назад, а пользователь нажимает
  на её строку
- **THEN** бот показывает тост «Время отмены истекло»
- **AND** задача остаётся выполненной

#### Scenario: Событие в сводке

- **WHEN** в сводке есть событие «Маникюр · 14:00–15:30»
- **THEN** оно показано строкой без кнопки

### Requirement: Актуальное состояние строк сводки

Сводка MUST запоминать состав в момент доставки и показывать актуальное
состояние задач: выполненное вхождение — «✅» и, у повторяющейся, следующий
срок; изменённую открытую — с текущими названием и сроком; удалённую или из
архива — без кнопки. Событие MUST показываться со временем на момент
доставки. Действие по устаревшей версии MUST NOT выполняться, касание MUST
NOT отменять действие новее выполнения: бот MUST сообщить «Задача уже
изменилась» и перерисовать сводку.

#### Scenario: Повторяющаяся задача

- **WHEN** пользователь нажимает в сводке на ежедневную задачу
- **THEN** строка показывает «✅ <название> · следующее завтра»
- **AND** задача остаётся в списке со сроком на завтра

#### Scenario: Задачу изменили после доставки

- **WHEN** после доставки сводки задачу переименовали, а пользователь нажимает
  на её строку по прежней версии
- **THEN** задача не выполняется
- **AND** бот показывает тост «Задача уже изменилась»
- **AND** сводка перерисовывается с новым названием

#### Scenario: Касание до обновления сводки

- **WHEN** Маша выполнила задачу, а Петя, не владелец household, нажимает на её
  строку в своей сводке раньше, чем сводка обновилась
- **THEN** бот показывает тост «Задача уже выполнена»
- **AND** строка перерисовывается в «✅ <название> · Маша» без кнопки

#### Scenario: Задачу изменили после выполнения

- **WHEN** Петя выполнил задачу из сводки, Маша сразу переименовала её, и Петя
  снова нажимает на строку
- **THEN** бот показывает тост «Задача уже изменилась»
- **AND** задача остаётся выполненной с новым названием

#### Scenario: Больше 20 задач

- **WHEN** в сводке 25 задач, и пользователь выполняет первую
- **THEN** сводка показывает те же 20 строк и «…и ещё 5»
- **AND** показывает «Выполнено 1 из 25»

#### Scenario: Повторяющееся событие прошло

- **WHEN** в сводке еженедельное событие «Бассейн · 07:00–08:00», а после его
  окончания задачу из сводки выполнили
- **THEN** строка события по-прежнему показывает «07:00–08:00» этого дня

#### Scenario: Задача удалена

- **WHEN** задачу из сводки удалили
- **THEN** при следующей правке сводки её строка показана без кнопки с
  отметкой «удалена»

### Requirement: Обновление сводки без касания

Последняя сводка каждого получателя, отправленная за последние 47 часов, MUST
обновляться без его действия, когда меняется состояние задачи из её снимка:
выполнение любым участником и путём (бот, HTTP API, Home Assistant), отмена,
изменение, назначение, удаление, архивирование списка — не позже чем через
минуту. Если отрисовка не изменилась (в том числе с наступлением полуночи),
сообщение MUST NOT править. Убранная или удалённая вручную сводка MUST NOT
возвращаться.

#### Scenario: Задачу выполнил другой участник

- **WHEN** у Пети, не владельца household, и Маши в сводке задача «Вынести
  мусор», и Маша отмечает её в своей сводке
- **THEN** в течение минуты строка в сводке Пети становится «✅ Вынести мусор ·
  Маша» без кнопки
- **AND** сводка Пети показывает «Выполнено 1 из N»

#### Scenario: Выполнение через Home Assistant

- **WHEN** задачу из сводки выполнили через Home Assistant
- **THEN** в течение минуты строка в сводке получателя показывает «✅»

#### Scenario: Отмена выполнения другим участником

- **WHEN** Маша отменила выполнение задачи в пределах окна отмены
- **THEN** в течение минуты строка в сводке Пети снова «☐ Вынести мусор · весь
  день» с кнопкой

#### Scenario: Ничего не изменилось

- **WHEN** задачи сводки не менялись с последней отрисовки, а наступила полночь
- **THEN** сообщение сводки не правится

#### Scenario: Сводка удалена вручную

- **WHEN** пользователь удалил сводку в клиенте или нажал «🗑 Убрать», а затем
  задачу из неё выполнили
- **THEN** сводка в чат не возвращается

### Requirement: Устаревшие кнопки сводки

Касание строки сводки, чьи кнопки старше срока жизни кнопок (24 часа), MUST
NOT менять задачу. Бот MUST перерисовать сводку с действующими кнопками и
сообщить тостом «Сводка обновлена — нажмите ещё раз».

#### Scenario: Сводка пролежала сутки

- **WHEN** сводку по запросу получили вчера в 20:00, она не менялась, а сегодня
  в 21:00 пользователь нажимает на строку задачи
- **THEN** задача не выполняется
- **AND** бот показывает тост «Сводка обновлена — нажмите ещё раз»
- **AND** повторное касание выполняет задачу

### Requirement: Сводка по запросу

Пользователь SHALL получать сводку на сегодня кнопкой «☀️ Сводка». Она MUST
строиться по текущему составу с учётом настройки состава, приходить сразу без
учёта тихих часов, работать при выключенной утренней сводке и вести себя как
утренняя (отметка, обновление, «🗑 Убрать», замена прежней). Заголовок —
«☀️ На сегодня · <дата>». Запланированную доставку утренней сводки она MUST
NOT отменять и сдвигать.

#### Scenario: Сводка днём

- **WHEN** в 15:00 пользователь нажимает «☀️ Сводка», а утренняя сводка
  осталась выше в чате
- **THEN** бот присылает сводку с заголовком «☀️ На сегодня · вс, 22 ноя» и
  задачами, созданными после утра
- **AND** утренняя сводка удаляется из чата

#### Scenario: Тихие часы и выключенная сводка

- **WHEN** у пользователя выключена утренняя сводка, сейчас его тихие часы, и
  он нажимает «☀️ Сводка»
- **THEN** сводка приходит сразу

#### Scenario: Утро после ручной сводки

- **WHEN** пользователь получил сводку по запросу в 07:00
- **THEN** утренняя сводка приходит в 08:30 как обычно и заменяет сводку по
  запросу

### Requirement: Состав утренней сводки

Пользователь SHALL выбирать состав задач и событий сводки: «все в семье» или
«только мои» — назначенные пользователю и общие (без исполнителя; для события
— без участника, чьё оно). Значение по умолчанию — «все в семье».
Переключатель MUST находиться в блоке «Утренняя сводка» экрана уведомлений и
показываться, только когда сводка включена. Число покупок от состава MUST NOT
зависеть.

#### Scenario: Только мои

- **WHEN** у Пети выбран состав «только мои», а на сегодня есть задача Пети,
  общая задача и задача Маши
- **THEN** сводка Пети содержит задачу Пети и общую задачу
- **AND** задачи Маши в ней нет

#### Scenario: Переключатель на экране уведомлений

- **WHEN** сводка включена и пользователь открывает экран уведомлений
- **THEN** блок «Утренняя сводка» показывает «Задачи в сводке: все в семье» и
  кнопку «👤 Только мои»
- **AND** после нажатия блок показывает «Задачи в сводке: только мои» и кнопку
  «👥 Все в семье»

### Requirement: Назначение задачи в сводке «только мои»

В составе «только мои» задача из сводки, назначенная другому участнику после
доставки, MUST исчезать из сводки, как выполненная исчезает из списка дел, и
MUST возвращаться, если исполнителя сняли или назначили пользователя. Итоги и
«Выполнено X из N» MUST считаться без исчезнувших задач.

#### Scenario: Задачу назначили другому после доставки

- **WHEN** у Пети состав «только мои», а общую задачу из его сводки назначили
  Маше
- **THEN** в течение минуты задача исчезает из сводки Пети
- **AND** итоги и «Выполнено X из N» пересчитываются без неё

#### Scenario: Назначение сняли

- **WHEN** после этого исполнителя сняли
- **THEN** задача снова появляется в сводке Пети с «👥»

### Requirement: Метки исполнителя в сводке

В составе «все в семье» строка задачи, назначенной другому участнику, MUST
содержать «👤 <имя>», в том числе если задачу назначили после доставки
сводки; задачи пользователя и общие — без метки. В составе «только мои»
строка общей задачи MUST содержать «👥», задачи пользователя — без метки.

#### Scenario: Чужая задача во всей семье

- **WHEN** у Пети состав «все в семье», а задача «Забрать посылку» назначена
  Маше
- **THEN** её строка в сводке Пети содержит «👤 Маша»

#### Scenario: Общая задача в моих

- **WHEN** у Пети состав «только мои», а задача «Вынести мусор» без
  исполнителя
- **THEN** её строка содержит «👥»

#### Scenario: Назначение после доставки во всей семье

- **WHEN** у Пети состав «все в семье», а общую задачу из его сводки назначили
  Маше
- **THEN** её строка в сводке Пети остаётся и содержит «👤 Маша»

### Requirement: Шапка утренней сводки

Утренняя сводка MUST начинаться заголовком с локальной датой получателя
(«☀️ Доброе утро! · сб, 21 ноя»), сводка по запросу — «☀️ На сегодня · <дата>»;
за заголовком идёт строка итогов с числом задач и событий сводки. После
того как в сводке выполнена хотя бы одна задача, MUST показываться строка
«Выполнено X из N», где N — задачи, видимые в сводке. Число открытых позиций покупок MUST показываться в подписи
кнопки «🛒 Покупки · N», а не отдельной строкой.

#### Scenario: Шапка и покупки

- **WHEN** на сегодня три задачи и одно событие, а в покупках семь позиций
- **THEN** сводка начинается с «☀️ Доброе утро! · сб, 21 ноя» и строки «3
  задачи · 1 событие»
- **AND** кнопка подписана «🛒 Покупки · 7», отдельной строки про покупки нет

#### Scenario: После отметки

- **WHEN** пользователь выполнил одну из трёх задач сводки
- **THEN** сводка показывает «Выполнено 1 из 3»

#### Scenario: Свободный день с покупками

- **WHEN** на сегодня нет задач и событий, а в покупках две позиции
- **THEN** сводка содержит заголовок и сообщение, что день свободен, без
  строки итогов
- **AND** кнопка подписана «🛒 Покупки · 2»

## MODIFIED Requirements

### Requirement: Утренняя сводка

Система SHALL отправлять утреннюю сводку пользователю, если она включена в его
настройках. Сводка MUST содержать задачи на сегодня, просроченные задачи и
события на сегодня в выбранном пользователем составе, а также количество
невыполненных позиций покупок. Событием на сегодня MUST считаться событие,
которое начинается сегодня или началось раньше и ещё не прошло. Время отправки
по умолчанию — 08:30 местного времени; пользователь может изменить его. Сводка
MUST содержать не более 20 строк задач и событий; при большем количестве MUST
показывать первые 20 и кнопку «Показать ещё». Если задач, событий и покупок
нет, сводка MUST содержать короткое сообщение об этом.

#### Scenario: Обычная сводка

- **WHEN** наступает 08:30 и у пользователя есть задачи на сегодня
- **THEN** бот отправляет сводку с задачами и просроченными
- **AND** показывает количество позиций в покупках на кнопке «🛒 Покупки»

#### Scenario: Пустой день

- **WHEN** на сегодня нет задач, событий и покупок
- **THEN** сводка сообщает, что день свободен
- **AND** не содержит пустых разделов

#### Scenario: Отключённая сводка

- **WHEN** пользователь отключил утреннюю сводку
- **THEN** сообщение не отправляется
- **AND** настройки других пользователей не меняются

#### Scenario: События в сводке

- **WHEN** наступает 08:30, на сегодня есть событие «Маникюр» с 14:00 до 15:30
  и идёт многодневное событие «Отпуск»
- **THEN** сводка содержит оба события
- **AND** событие не попадает в раздел просроченных

### Requirement: Настройки уведомлений

Система SHALL позволять каждому пользователю независимо настраивать включение
напоминаний, утренней сводки и уведомлений о назначении, lead time, время
сводки, состав сводки, время вседневного напоминания, тихие часы и часовой
пояс. Значения MUST валидироваться: lead time от 5 до 1440 минут, время в
формате `HH:MM`, часовой пояс из базы IANA, состав сводки — «все в семье» или
«только мои». Изменения MUST применяться без перезапуска сервиса и MUST не
затрагивать других участников.

#### Scenario: Изменение lead time

- **WHEN** пользователь устанавливает lead time 60 минут
- **THEN** следующие напоминания приходят за час до срока
- **AND** уже запланированные напоминания пересчитываются

#### Scenario: Некорректный часовой пояс

- **WHEN** пользователь вводит `Mars/Olympus`
- **THEN** система отклоняет значение
- **AND** сохраняет прежний часовой пояс

#### Scenario: Независимость настроек

- **WHEN** один участник отключает утреннюю сводку
- **THEN** другие участники продолжают получать свои сводки
- **AND** настройка хранится отдельно для пользователя

#### Scenario: Состав сводки без явного выбора

- **WHEN** пользователь ни разу не менял состав сводки
- **THEN** его сводка содержит задачи и события всей семьи
