# Spec Delta

## ADDED Requirements

### Requirement: Состав «Моих задач»

Экран «👤 Мои задачи» и число на кнопке «Мои задачи» в главном меню SHALL
включать открытые задачи неархивных списков, назначенные пользователю, и
общие задачи (без исполнителя). Строка общей задачи MUST содержать отметку
«👥»; строка задачи, назначенной пользователю, — без отметки. Задачи,
назначенные другим участникам, MUST NOT входить.

#### Scenario: Свои и общие задачи

- **WHEN** у household три открытые задачи: назначенная Пете, без исполнителя
  и назначенная Маше, а Петя открывает «👤 Мои задачи»
- **THEN** экран показывает две задачи: свою без отметки и общую с «👥»
- **AND** кнопка в меню подписана «👤 Мои задачи · 2»

#### Scenario: Счётчик после назначения

- **WHEN** общую задачу назначили Маше
- **THEN** у Пети число на кнопке «Мои задачи» уменьшается на единицу
- **AND** у Маши строка этой задачи показывается без «👥»

#### Scenario: Нет ни своих, ни общих задач

- **WHEN** все открытые задачи household назначены другим участникам, а Петя
  открывает «👤 Мои задачи»
- **THEN** экран сообщает, что нет ни его, ни общих задач
