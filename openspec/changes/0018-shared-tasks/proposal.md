# Proposal

## Why

Задача без исполнителя сейчас живёт по-разному в разных местах: в «Моих
задачах» её нет ни у кого, напоминание о ней получает только автор, а у
задачи из Home Assistant или голоса — все. Для семьи естественнее одно
правило: нет исполнителя — задача общая, её видят и о ней узнают все, а кому
нужно — ставят исполнителя. Когда напоминание об общей задаче приходит
нескольким людям, после выполнения у остальных остаются устаревшие копии с
рабочими кнопками — их тоже нужно снимать.

## What Changes

- Вводится понятие «общая задача»: открытая задача без исполнителя. Это не
  новое поле, а правило, одинаковое для всех экранов и уведомлений.
- «👤 Мои задачи» и счётчик на этой кнопке меню показывают задачи,
  назначенные мне, и общие задачи; общие помечены «👥».
- **BREAKING (поведение):** напоминание о задаче без исполнителя получает
  каждый участник с включёнными напоминаниями, а не только автор. Задачи и
  события с исполнителем — как раньше. Напоминание о событии без участника,
  чьё оно, следует тому же правилу. Задачи участника, исключённого из
  household, становятся общими.
- Уведомление о задаче (напоминание, отложенное напоминание, назначение),
  которую выполнили не из этого сообщения, перерисовывается в «✅ Выполнено:
  <название>» с одной кнопкой «🗑 Убрать», с именем выполнившего, если это
  другой участник, и удаляется само через 10 минут после выполнения. Если
  выполнение отменили в эти 10 минут, уведомление возвращается с кнопками.
  Убранное или удалённое вручную уведомление синхронизация не возвращает.
- Назначение задачи другому участнику обрабатывается так же: у остальных
  уведомление становится «👤 Назначено: <название> · Маша» с «🗑 Убрать» и
  удаляется через 10 минут, а если исполнителя в эти минуты сняли —
  возвращается. Уведомление самого исполнителя не меняется. Отложенное
  напоминание человека, у которого задачу забрали, больше не приходит.
- Фильтр по исполнителю в HTTP API и поиске остаётся буквальным: «исполнитель
  = X» не включает общие задачи.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `task-management`: новое требование «Общая задача».
- `telegram-rich-ui`: новое требование о составе «Моих задач» и счётчика.
- `notifications-reminders`: «Получатель напоминания» — без исполнителя
  получают все участники с включёнными напоминаниями, отложенное — только
  если задача не назначена другому; новые требования об уведомлении о
  задаче, выполненной не из него или назначенной другому, и о возврате
  уведомления.

## Impact

- `src/jobs/scheduler.rs` (`plan_reminders`), `src/jobs/notice.rs`
  (`recipient_selected`) — правило получателя.
- `src/storage/repositories/items/stats.rs`, `src/domain/search.rs`,
  `src/telegram/bot/screens.rs` (`mine`, меню) — состав «Моих задач».
- `src/jobs/` — новый шаг планировщика синхронизации отправленных
  уведомлений с выполнением; `src/telegram/bot/notify/` — экран «✅ Выполнено ·
  <имя>»; `src/telegram/outbox.rs` — правка без повторной отправки исчезнувшего
  сообщения.
- Миграция `0026` — отметка закрытия отправленного уведомления и индекс под
  выборку шага.
- Зависит от 0017: отложенное удаление и его отмена, удаления уборки, отметка
  убранных уведомлений.
- `docs/telegram-ux.md`, `docs/domain-model.md` — правило общей задачи.
- Совместимость: участники начнут получать напоминания об общих задачах,
  которые раньше получал только автор.
