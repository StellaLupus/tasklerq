# Spec Delta

## ADDED Requirements

### Requirement: Общая задача

Открытая задача без исполнителя SHALL считаться общей задачей household
независимо от того, кто и каким способом её создал (бот, HTTP API, Home
Assistant, голос). Общая задача MUST входить в выборки «мои задачи» каждого
участника. Назначение исполнителя MUST делать задачу личной задачей
исполнителя, снятие исполнителя — снова общей. Фильтр по конкретному
исполнителю MUST NOT включать общие задачи.

#### Scenario: Задача из Home Assistant

- **WHEN** HA Assist создаёт задачу без исполнителя
- **THEN** задача общая и входит в «мои задачи» каждого участника

#### Scenario: Назначение и снятие исполнителя

- **WHEN** общей задаче назначают исполнителя Машу
- **THEN** задача входит в «мои задачи» только Маши
- **AND** после снятия исполнителя снова входит в «мои задачи» каждого
  участника

#### Scenario: Фильтр по исполнителю

- **WHEN** участник запрашивает через HTTP API задачи с исполнителем Маша
- **THEN** ответ содержит только задачи, назначенные Маше
- **AND** общие задачи в ответ не входят
