# Proposal

## Why

После 0013 и 0014 консоль настраивает инсталляцию, но повседневное
администрирование по-прежнему требует `docker compose exec tasklerq tasklerq
admin …`: список household, выпуск и отзыв API-токенов, добавление участника по
Telegram ID, статистика очередей, выгрузка. Особенно это мешает режиму `multi` —
там household создаются через CLI или бота, а ссылку-claim владельца (0014)
негде выпустить для нового дома. Этот change доводит консоль до паритета с
`tasklerq admin`, не убирая CLI.

## What Changes

- Страница household: список (название, часовой пояс, владелец или его
  отсутствие, число участников, открытых задач и активных токенов), создание
  (с теми же правилами `single`/`multi`, что у CLI), мягкое удаление с
  подтверждением вводом названия.
- Страница household — участники: список (имя, роль, дата вступления, без
  Telegram ID целиком), добавление по Telegram ID с ролью, ссылка-claim
  владельца для household без владельца (в том числе в `multi`).
- API-токены household: список (имя, префикс, scopes, последнее
  использование, состояние), выпуск с показом один раз, отзыв с
  подтверждением.
- Очереди: число заданий по статусам для `telegram_updates`, `outbox`,
  `capture_jobs`, `notification_deliveries` и возраст самого старого готового
  обновления, с автообновлением; без содержимого.
- Выгрузка household в JSON из консоли — тот же формат, что
  `tasklerq admin export`, без хешей токенов и секретов. Выгрузка записывается
  в аудит в обоих путях (у CLI сейчас такого события нет).
- В режиме `single` выбор household не показывается; в `multi` страницы
  открываются из списка household.
- CLI остаётся без изменений, кроме события аудита выгрузки; консоль и CLI
  вызывают одни и те же функции `src/admin`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `admin-console`: новые требования — управление household, участниками,
  API-токенами, просмотр очередей, выгрузка, подтверждение опасных действий.
- `security-privacy`: «Раскрытие, выгрузка и удаление данных» — выгрузка из
  консоли наравне с CLI.

## Impact

- `src/admin_console/` — страницы household, участников, токенов, очередей,
  выгрузки и шаблоны к ним.
- `src/admin/mod.rs` — без изменения поведения; возможно, выделение функций
  для списка участников household, если их нет.
- `docs/deployment.md` §9.1 (консоль как основной путь, таблица соответствия
  команд CLI и страниц консоли).
- Миграция: значение `audit_event_type` `household_exported`.
- Совместимость: поведение CLI и бота не меняется, кроме нового события аудита
  при выгрузке.
